# Life Sciences Market Update 2026

LSC's market-update site tracking major life sciences investments and
projects across Ireland, published via GitHub Pages.

## Live site

https://lifescienceconsultants.github.io/life-sciences-market-update-2026/

## Structure

- `index.html` — main market-update page (Ireland's life sciences growth,
  investment breakdown by region and company)
- `.nojekyll` — disables GitHub Pages' Jekyll build step
- `robots.txt` — search engine crawl rules

## Updating the site

1. Edit `index.html` locally (or via GitHub's web editor)
2. Commit the change to the `main` branch
3. GitHub Pages rebuilds automatically within a minute or two
